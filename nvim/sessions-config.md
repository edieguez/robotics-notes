# Sessions, config & search

## Sessions (persistence.nvim)

- `Space-qs` - restore the session for the current directory
- `Space-qS` - pick a saved session from a list
- `Space-qd` - stop saving the current session. Quitting after this will not save it
- `Space-qq` - quit all windows (`:qa`). Persistence saves the session on exit

## Config & plugins

- `Space-fc` - find config: open the Neovim configuration directory
- `Space-l` - open the Lazy.nvim plugin manager

## Finding things (snacks.nvim)

- `Space-ff` - find files
- `Space-fr` - recent files
- `Space-/` - grep in the project
- `Space-sk` - search keymaps
- `Space-sp` - search plugin specs (Lazy)
- `Space-e` - file explorer (`mini.files`)
